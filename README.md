# example-07 案例复现仓库

本项目为软件开发综合实践第七次作业案例复现仓库。

## 包含案例
1. **Three.js 旋转展示台** (`showcase.html` / `showcase.js`):
   - 展台底座、展品组合（立方体、球体、圆环体）
   - 环境光与方向光双光源照明
   - 缓转动画与窗口 resize 自适应
   - OrbitControls 鼠标环顾交互
2. **A-Frame 校园角标主题小场景** (`campus.html`):
   - 天空、草地地平面
   - 教学楼实体模型
   - 飘动旗帜动画与脉动路灯点光源
   - 相机初始位与 WASD 漫游交互
